# A1 检验集预注册（2026-10-28，写于检验集评分之前）

本文件和冻结的代码在同一个 commit 中提交。检验集预测数据生成后，不再修改方法或参数。

## 冻结的方法

- 代码：`pilot/scripts/proxy_select.py`，用默认参数运行（`python pilot/scripts/proxy_select.py pilot`）。
  - α = 0.1，β = 0.5，可测变异池占 50%，200 次重复，seed 0，预算 k ∈ {2, 4, 8, 12, 16}。
  - 不加集成假设，不加测量误差（这两项在开发集上没有带来改进，只作为消融实验报告）。
- 主输出：后验加权预测 `rho_bma`，即留出变异上与实测效应的 Spearman，取 k = 8。
- 主场景：hide_matched，即去掉元件本身细胞类型的轨道。没有匹配轨道的元件用 all 场景（两者相同）。
- 预测：AlphaGenome ALL_FOLDS，所有生物样本的 CAGE/DNase/ATAC。

## 数据划分

- 开发集（已看过，不参与检验）：PKLR-48h、F9、HNF4A、IRF6、BCL11A。PKLR-24h 与 PKLR-48h 共享区域，也排除。
- 检验集：其余 17 个人类细胞实验，分布在 11 个基因组区域：FOXE1、GP1BA、HBB、HBG1、IRF4、LDLR（含 LDLR.2）、MSMB、MYCrs11986220、MYCrs6983267、SORT1（含 SORT1-flip、SORT1.2）、TERT（GAa、GBM、GSc、HEK）。
- 分析单位：**区域**（11 个）。同一区域的多个实验先取平均，因为它们共享同一组预测，彼此不独立。实验层面（17 个）的结果作为补充报告。

## 假设与判定

| 编号 | 假设 | 检验 |
|---|---|---|
| H1 | 选点方式重要：disc 的 rho_bma 高于随机选点 | 11 个区域上的配对单侧 Wilcoxon 符号秩检验，p < 0.05 |
| H2 | 有实用价值：disc 的 rho_bma 高于不用标签的全轨道平均 | 平均差 ≥ 0.03，且至少 7/11 个区域为正 |
| H3（次要） | disc 优于"高预测效应"选点 | 配对单侧 Wilcoxon，p < 0.05 |

判定规则：

- H1 和 H2 都成立：GO，按原定 A1 框架写论文（"约 8 个实测值即可为未覆盖的细胞类型选出代理"）。
- 只有 H1 成立：A1 的实用结论不成立。论文需要重新定位，例如改为选点策略本身，或者"轨道选择的不确定性"。届时与评审讨论后再定。
- H1 不成立：放弃 A1 的核心主张。
