# 论文叙述逻辑（按 Bioinformatics 审稿视角，2026-11-04）

这份文件定下论文的主线：要回答哪几个问题、按什么顺序回答、每个结果在论文里起什么作用。作者改写正文时以它为准。以后再出现新结果，用第 6 节的规则判断它放在哪里，不按结果好不好看来决定。

## 1. 审稿人读这篇论文时问的五个问题

Bioinformatics 的 Original Paper 审稿，通常落在这五点上：

1. **问题**：问题是否真实存在，是否重要？
2. **方法**：方法新在哪里，比现有做法好在哪里？
3. **验证**：数据是否独立，基线是否合理，统计是否得当？
4. **工具**：工具能不能拿来就用？
5. **边界**：方法在哪里不管用，作者有没有说清楚？

论文每一节都应当服务于其中一个问题。不服务于任何问题的结果，不进正文。

## 2. 一句话主张和适用条件

**主张**：实验室测出约 8 个经过挑选的变异后，TrackPilot 就能在约一千个基础模型轨道中决定用哪些。
- 有匹配轨道时，结果不比直接用匹配轨道差；
- 匹配轨道缺失、但其他细胞类型的轨道带有信号时，它能找到替代。

**条件**：至少有一个轨道或轨道组合大致跟得上实验测量。离所有已有轨道都很远的细胞类型，8 个测量值不够。

**原则**：一个结果要算确证，它用到的数据必须没有参与过修改方法。

由此得出一条硬约束：**"有匹配轨道时不比它差"的确证只来自 Siraj**（以及换成 Enformer、换成未见检查点后的 Siraj）。Kircher 正是加入元数据先验的起因，不能再拿来证明先验有效。

## 4. 论文主线：按问题展开

### 问题 0：这个问题真实存在吗？（引言）
- **证据**：按名字匹配的轨道，在 1,018 个轨道中的排名从第 1 到第 27 不等；在 PKLR 上把 K562 轨道换成 HepG2 轨道，生物学结论随之改变；很多实验室常用的细胞没有对应轨道。
- **证据的身份**：开发阶段的观察，只用来说明动机，不当作检验结果。
- **对应审稿问题**：1。

### 问题 1：有匹配轨道时，会不会比直接用它更差？（结果 3.1）
- **确证**：Siraj P1、P2（预注册，冻结的 v2）。
- **佐证**：Enformer 在 Siraj 上的结果；未见检查点下的 Siraj P1。
- **如何交代 Kircher**：说明它是加入先验的原因（v1 在 7/11 个区域更差），冻结后的复核只作描述性报告，不放进小节标题，也不进讨论部分的结论。
- **对应审稿问题**：2、3。

### 问题 2：匹配轨道缺失时，能找到替代吗？（结果 3.2）
- **确证**：Kircher H1、H2（v1，预注册）；Siraj P3、P4（v2，预注册）。两套数据、两个方法版本独立给出同一结论，这是全文最强的证据。
- **佐证**：Enformer；未见检查点。
- **说明增益来自哪里**：增益集中在默认结果差的位点；IRF4 作为直观例子。
- **对应审稿问题**：3。

### 问题 3：为什么这样设计？每个组成部分都要有对照（结果 3.3–3.4）

| 设计选择 | 不这样做的对照 | 结果 |
|---|---|---|
| 挑选能区分轨道的变异来测 | 随机挑选 | 随机挑 8 个比不测还差（Siraj 0.342 对 0.391，Kircher 0.286 对 0.296）；挑选的面板胜过随机（122/125 个位点，9/11 个区域） |
| 把校准积分掉，而不是直接拟合 | 岭回归、LASSO、重新拟合匹配均值 | 都更差；重新拟合时斜率可能反号 |
| 从匹配轨道出发（元数据先验） | v1 均匀先验 | 有匹配轨道时 v1 更差（这是先验的来源，见第 3 节） |
| 报告后验平均，不挑单个轨道 | CODA 式挑选单轨；同一基线改报平均 | 改报平均救回 0.016–0.026；TrackPilot 仍领先 0.018；但均匀先验 + EIG 选点 + 平均的基线与 TrackPilot 持平（差 ≤ 0.006） |
| 一轮下单 | 逐个挑选 | 差别 ≤ 0.005，在预设等价界内 |

- **对应审稿问题**：2。审稿人想知道的是"是哪个部件在起作用"，这张对照表回答它，但要如实说明它的限度：回归基线与 TrackPilot 在不止一处不同，不能单独归因于"积分掉校准"；与均匀先验平均基线持平说明，在没有匹配轨道时，增益来自"校准后的平均"，而不是选点准则本身。

### 问题 4：用户怎么用？（方法"测量数量"、结果 3.3、实现部分）
- k 由用户设定，默认 8。8 是实际预算，不是推导出的最小值。学习曲线显示 2 个不够，4 个开始超过默认结果。
- 可以分轮测量，也可以一次下单。
- **对应审稿问题**：4。

### 问题 5：在哪里不管用？（结果 3.6–3.8、讨论中的局限）
三组情况（不把它们当作测量过的"生物学距离"排序）：
1. 人类细胞系，本身没有轨道，但有相近的轨道（事后分析，结果正面）；
2. 小鼠细胞系（预注册，未成立：比随机好，但不比全轨道均值好）；
3. 诱导神经元（预注册，失败：轨道整体几乎预测不了实验结果；只有活性最高的四分之一片段有可测信号，那里也只是持平）。

然后给出对策：适用性检查（预注册，A1、A2 成立）。它的作用是发现测量值与轨道不符时退回默认结果，它不能把失败变成成功。
- **对应审稿问题**：5。两项失败的检验划出了方法的边界，并不推翻问题 1 和问题 2 的结论，因为它们回答的是另一个问题。

## 6. 新结果的纳入规则

依次问四个问题（先查报告义务，再看相关性）：

1. **预注册时是否承诺过要报告它？** 承诺过：必须报告，至少放进补充材料，不论结果好坏，也不论它是否属于第 4 节的问题。
2. **它回答第 4 节的哪个问题？** 一个也不回答、又没有报告义务：不进论文，留在仓库里。
3. **它会改变哪条结论或适用条件？** 会：进正文。不会：放补充材料，正文最多引用一句。
4. **它的级别是什么？** 确证、佐证、事后或描述性，正文中必须写明，与第 3 节的时间顺序保持一致。

结果好看，不是进正文的理由；结果难看，也不是不报的理由。
