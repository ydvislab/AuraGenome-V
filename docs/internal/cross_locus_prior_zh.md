# 跨位点共享先验（预注册扩展，2026-11-03）

本文件在运行任何跨位点结果之前写好并提交。λ 在开发位点上选定、提交之后，才运行检验位点。

## 1. 要回答的问题

一个实验室通常在同一种细胞里研究多个位点。在已研究过的位点上，实验室各测了一个 8 变异的试点面板。

问题：把这些位点的后验带到新位点上，能否在测同样多变异的情况下，明显提高新位点的预测？

现在的 TrackPilot 每个位点都从同一个先验出发。但"哪类轨道像这种细胞"是跨位点共享的。

## 2. 方法（只改先验，其余冻结）

对目标位点 i、细胞类型 c、情景 s：

1. 从同一细胞类型的其他位点中随机取 m 个，记为 J。抽样用 `numpy.random.default_rng([1, rep, i])`，i 为位点在字母序中的编号。
2. 每个位点 j∈J 用单位点 TrackPilot（冻结 v2，同一情景，同一重复 rep 的可测池）选 8 个变异，读入实测值，得到后验权重 w_j(h)。h 为假设：单条轨道，或锚点。
3. 跨位点权重 q(h) = J 中各位点 w_j(h) 的平均。各位点按假设名对齐；某位点缺失的假设记为 0。
4. 目标位点的先验 = (1 − λ) × 原先验 + λ × q，然后照常用冻结的 TrackPilot 选面板、拟合和预测。

- **信息使用**：目标位点自己的标签只有它的 k 个面板变异。其他位点只贡献各自 8 个面板变异的标签，不用任何评估变异。
- **不变的部分**：α、β、π、家族阈值、可测池（`default_rng([0, rep])`，50%）、评估集（池外变异），以及判别面板的选择规则。
- **不适用于 Kircher**：Kircher 每个元件是不同的细胞系，没有"同一细胞多位点"的情形。

## 3. 数据划分

- 数据：Siraj 125 个位点，标签相对参考寡核苷酸（`data/siraj_ref`），AlphaGenome ALL_FOLDS 预测。
- **开发位点**：用 `numpy.random.default_rng(2611).choice(125 个按字母序排列的位点, 40, replace=False)` 抽 40 个，只用来选 λ。
- **检验位点**：其余 85 个。
- 其他位点 J 可以来自全部 124 个其他位点，包括开发位点。它们只提供面板标签，和目标位点不重叠。
- 重复：前 20 次（rep = 0–19），开发和检验相同。单位点基线用同一段代码、同样的重复重算，因此是配对比较。

## 4. 选 λ（开发位点）

- 网格：λ ∈ {0.25, 0.5, 0.75, 0.9}，m = 10。
- 准则：C3（无匹配轨道）、k = 8 时 rho_bma 的位点平均值最大。差距小于 0.002 时取较小的 λ。
- 选定后写进本文件第 7 节并提交，然后才运行检验位点。

## 5. 预注册假设（85 个检验位点，单位为位点，两个细胞类型先平均）

- **X1（主）**：C3，k = 8，跨位点减单位点。平均 ≥ +0.02，且单侧 Wilcoxon P < 0.05。
- **X2（安全）**：C1（保留匹配轨道），k = 8，跨位点减匹配均值。单侧 95% bootstrap 下界 > −0.02，且差值 < −0.05 的位点比例的 Clopper–Pearson 单侧上界 ≤ 15%。界值与 P1、P2 相同。
- **判定**：X1 和 X2 都成立，判为"跨位点先验在不损失安全性的前提下提高了无匹配轨道时的预测"。否则如实报告哪一条没有成立。

**次要（描述性，不做判定）**
- C2，k = 8，跨位点减单位点。
- 标签效率：跨位点 k = 4 与单位点 k = 8 比较。
- m 的影响：m ∈ {1, 3, 10, 30}。
- 增益与默认差距的关系（同 `reframe_report.py` 的四分位分组）。

## 6. 局限（预先写明）

- 所有位点来自同一研究、同一种 MPRA 设计。跨位点信息里可能包含实验设计本身的特征。这符合"同一实验室、同一实验"的使用场景，但不能推广到不同实验之间。
- K562 和 HepG2 都被 AlphaGenome 覆盖。C3 仍是把轨道藏起来模拟的。
- 只用了 20 次重复（冻结运行是 200 次），用于节省计算。单位点基线也用这 20 次重新计算。

## 7. 冻结记录

开发位点（40 个，20 次重复），C3，k = 8，m = 10，按轨道汇总：

| λ | 跨位点 | 单位点 |
|---|---|---|
| 0.25 | 0.4516 | 0.4454 |
| 0.5 | 0.4543 | 0.4454 |
| 0.75 | 0.4562 | 0.4454 |
| 0.9 | 0.4569 | 0.4454 |

**选定 λ = 0.75**：0.9 只高 0.0007，按规则取较小的 λ。

开发位点上的增益约 +0.011（32/40 个位点为正），低于 X1 的界值 0.02。界值不改，检验照原规格进行。

**规格外的一次开发探索（如实记录）**：看到上表后，在开发位点上试了"按生物样本汇总"。做法是把其他位点的后验按生物样本求和，再按目标位点的原先验分给该生物样本的各条轨道。结果更差，C3、k = 8 时只高 +0.003 到 +0.005，所以不采用，检验仍按第 2 节的"按轨道汇总"。代码保留在 `cross_locus.py --level biosample`，结果在 `pilot/results/cross_locus/dev_biosample/`。

检验命令：`python pilot/scripts/cross_locus.py run --stage test --lam 0.75`，然后 `evaluate`。

## 8. 结果（85 个检验位点，2026-11-03）

判定表在 `results/a1/cross_locus/decision.txt`，次要结果在 `secondary.tsv`，补充材料为表 S9。

- **X1 未成立**：C3、k = 8，跨位点减单位点 = +0.012，65/85 个位点为正，单侧 Wilcoxon P = 4e-8。提升非常一致，但幅度没有达到 0.02。
- **X2 成立**：C1、k = 8，跨位点减匹配均值 = +0.014，下界 +0.007，3/85 个位点变差超过 0.05，上界 0.089。
- **判定**：未得到支持。论文中写作"一致但幅度小"的预注册扩展，不作为主要贡献。

描述性结果：
- C3、k = 4 时跨位点多出 +0.022；
- m 从 1 增加到 30，增益从 +0.006 升到 +0.013，增长逐渐变平；
- 有匹配轨道（C1）且 k = 4 时：单位点 TrackPilot 低于匹配均值（0.466 对 0.476），跨位点则与之持平（0.477）。
