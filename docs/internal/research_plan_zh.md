# 研究方案：让基因组 AI 的预测"可核查"——基于多源证据可视化与大模型的变异效应预测验证框架

> 2026-10-28。目标期刊：*Bioinformatics*（Original Paper，Genome analysis 分区）。
> 定位：像 Circos 当年用可视化推进比较基因组分析一样，**用计算机方法（可视化 + 大模型）推进"基因组 AI 时代"的变异解读分析**。贡献的落脚点是生物信息分析本身：研究者能更可靠地筛选变异、发现模型错误、避免被错误预测误导。
> 依据：[novelty_report_zh.md](novelty_report_zh.md)（含第 7 节补查）。工具名暂定 **AuraGenome-V**（V = Verify），后续可以改。

---

## 1. 一句话

**基因组基础模型（AlphaGenome、Borzoi 等）现在能对任意变异预测上千条功能轨道，但研究者无法判断"这一条预测在这个位点、这个细胞类型上靠不靠谱"。AuraGenome-V 把模型自身的可靠性信号、多个模型之间的分歧和实验证据汇总到一个可视化分析框架里，并用"必须引用证据"的大模型助手解释结果，帮助研究者在变异解读中区分可信和不可信的预测。**

---

## 2. 背景与动机（引言要讲的四件事）

1. **基因组 AI 正在成为变异解读的基础设施。**
   - AlphaGenome 一次预测 5930 条人类功能轨道；Atlas 预计算了约 90 亿个变异的分数。
   - EVEE 为 420 万个 ClinVar 变异提供分数和 LLM 解释。
   - 2026 年起，模型权重和 API 均可免费用于非商业研究。
2. **但这些预测并非处处可靠，而且领域内已有多项证据：**
   - Basenji2 多个副本在 eQTL 上超过一半的情况方向不一致，在参考序列上常常"错得很自信"（Bajwa 2024）；
   - 与饱和突变 MPRA 的一致性可能很低，例如 PKLR 启动子 ρ≈0.23（RegTrust 2026）；
   - DNA 语言模型的高分常常只是序列"好预测"，不同模型给出的重要元件完全不重叠（Dark Regulome 2026）；
   - 不同的解释方法对同一个预测给出互相矛盾的解释（2026 年立场论文）。
3. **现有工具只给分数，不给"可信度"。**
   - AlphaGenome Atlas、EVEE 都没有不确定性和模型分歧的展示；
   - EVEE 的 LLM 解释没有做过忠实性检验；
   - RegTrust 只能对单条序列、单个细胞系给出一个可信度等级。
4. **因此需要一个分析框架。** 它要回答三个问题：这个预测和哪些证据一致、和哪些冲突？冲突出现在哪些轨道和细胞类型？总体上该不该信？它还要能在变异集合的规模上用来筛选，而不只是逐个看。

---

## 3. 科学问题

> **核心问题：在变异解读中，如何系统地判断基因组基础模型的预测在何处可信，并把这种判断变成研究者能直接使用的分析结果？**

| 子问题 | 内容 | 对应的方法 |
|---|---|---|
| **SQ1 可靠性刻画** | 对一个变异，在每条轨道 × 每个细胞类型上，模型预测有多可靠？哪些计算信号能提示"这里可能错了"？ | 可靠性画像（§4.2） |
| **SQ2 证据对照** | 预测与独立证据（观测到的功能轨道、MPRA/SGE、eQTL、保守性、ClinVar）一致还是冲突？ | 证据对照层（§4.3） |
| **SQ3 可视化分析** | 如何在"变异集合 → 单个变异 → 轨道/细胞类型 → 碱基"的多个尺度上，让研究者快速找到"预测与证据不一致"的地方？ | 多尺度可视化（§4.4） |
| **SQ4 可信的语言解释** | 大模型解释如何做到每句话都可追溯到证据，不编造，不夸大？ | 证据约束的 LLM 助手（§4.5） |

## 4. 方法

### 4.1 模型层：多模型、多副本预测

| 模型 | 用途 | 获取方式 |
|---|---|---|
| **AlphaGenome** | 主模型：5930 条人类轨道，碱基级分辨率；含剪接 | API（非商业免费）；权重已于 2026 年 1 月在 Hugging Face/Kaggle 开放（非商业条款），含 all-folds 版本 |
| **Borzoi** | 第二模型，RNA-seq 覆盖度等；**官方提供 4 个副本（rep0–rep3）**，可直接得到副本间分歧 | CREsted、gReLU（Genentech HF）、borzoi-pytorch 等移植版本（各版本许可证不一致，使用前需核对） |
| Enformer（可选） | 第三模型，用于跨模型对照 | 公开权重 |
| Evo 2 / EVEE 分数（可选） | DNA 语言模型的视角；用于检验"可预测性"混杂 | EVEE 预计算表（Zenodo） |

**输出**：对每个变异，得到参考/突变等位基因在各轨道、各细胞类型上的预测，以及效应量（突变 − 参考）。

### 4.2 可靠性画像（SQ1）

对每个"变异 × 轨道 × 细胞类型"计算一组信号。这些信号在机器学习文献中已被提出，我们把它们**系统化，并在变异解读中统一使用**：

| 信号 | 含义 | 来源 |
|---|---|---|
| 副本分歧 | Borzoi 4 个副本（及 AlphaGenome 各折）效应**方向**是否一致，幅度的离散程度 | Bajwa 2024 |
| 跨模型分歧 | AlphaGenome、Borzoi、Enformer 对同一轨道类型的效应是否一致 | Dark Regulome 2026 |
| 归因一致性 | 变异附近的归因是否落在已知 motif 上；归因是否在副本间稳定 | RegTrust 2026、tangermeme |
| 适用域距离 | 序列与训练数据的距离（嵌入空间距离） | RegTrust 2026 |
| 参考位点的预测质量 | 该位点、该细胞类型上，**参考序列的预测与实际观测轨道（ENCODE）是否吻合**。如果连参考都预测不准，变异效应更不可信 | 本工作提出的组合用法（需验证） |
| 可预测性混杂 | 变异分数是否主要由序列复杂度、重复序列解释（简单特征基线） | Dark Regulome 2026 |

**输出**：每条预测一个可靠性画像（多维），以及一个汇总的可靠性分。汇总方式在验证集上学习或标定，避免拍脑袋定权重。

### 4.3 证据对照层（SQ2）

| 证据 | 用法 |
|---|---|
| 观测功能轨道（ENCODE/Roadmap 等） | 与参考序列的预测逐位点对照（见上面"参考位点的预测质量"） |
| MPRA / 饱和突变 MPRA（Kircher 2019，21 个元件，有门户可下载） | 直接检验变异效应 |
| 饱和基因编辑 SGE（Findlay 2018 BRCA1，3893 个 SNV） | 直接检验变异效应（编码区及剪接） |
| 精细定位的 eQTL（GTEx 等） | 检验效应方向与细胞类型 |
| 保守性、ClinVar（含评审星级） | 辅助证据 |

**输出**：对每个变异，列出"支持 / 冲突 / 无证据"的证据清单，每条证据可追溯到原始数据。

### 4.4 多尺度可视化（SQ3）

| 尺度 | 视图 | 用来回答 |
|---|---|---|
| 变异集合（数百到数万个） | 变异 × 可靠性维度的矩阵，可排序、可筛选；也可以用**全基因组环形概览**展示可靠性景观（延续 Circos/AuraGenome 的表达方式） | 哪些变异的预测值得信？哪些区域普遍不可信？ |
| 单个变异 | **轨道 × 细胞类型的"一致性热图"**：颜色表示效应方向和大小，标记表示副本或模型分歧以及与证据是否冲突；可按轨道类型和组织本体分组折叠 | 这个变异在哪些细胞类型、哪类轨道上的预测可靠？冲突在哪里？ |
| 单条轨道 | 参考/突变的预测曲线 + 实际观测曲线 + 各副本的预测带 | 模型在这个位点本身就预测得准吗？ |
| 碱基 | 归因 logo + motif 注释 + 各副本归因的一致性 | 预测是靠合理的 motif，还是靠无关的序列特征？ |

**设计原则**：
- 不是把所有信号都画出来，而是**按"与证据不一致"的程度排序和突出显示**，让研究者先看最可能出错的地方；
- 所有汇总都能下钻到原始证据。

### 4.5 证据约束的 LLM 助手（SQ4）

延续 AuraGenome 的大模型能力，但**反过来约束它**：

1. **结构化解析**：用户用自然语言提问，例如"这个变异在肝细胞里会影响 PCSK9 表达吗？靠谱吗？"。问题先被解析为结构化查询（延续 E4 的"规格 + 规则检查"思路），再驱动视图。
2. **引用证据**：LLM 只能基于 §4.2–4.3 产出的证据清单写解释，**每句话必须引用证据编号**。
3. **自动核查**：程序逐句检查引用是否存在、方向是否一致。不一致的句子会被标红或删除。
4. **明确报告不确定性**：可靠性低时，解释必须说"模型在此处不可靠"，不允许给出确定性结论。

这一部分直接回应 EVEE 式"无约束 LLM 解释"的风险，是本工作在计算机方法上的另一个贡献点。

## 5. 评估（按 *Bioinformatics* 的习惯，以真实数据上的计算评估为主）

### R1. 可靠性画像能否识别"错误的预测"（核心计算评估）
- **数据**：Kircher 2019 饱和突变 MPRA（21 个元件）、Findlay 2018 BRCA1 SGE，以及精细定位的 eQTL 方向。
- **任务**：把模型预测与实验测得的效应比较，定义"预测错误"（例如方向错误，或效应大小严重偏离）。检验可靠性画像能否把错误预测和正确预测区分开（AUROC）。
- **对照**：单一信号（只用副本分歧、只用 RegTrust 式的两轴）、无信号基线。
- **期望结论**：多源画像优于单一信号。按可靠性筛选后，变异优先排序的精确率提高。

### R2. 用于变异优先排序的增益
- **任务**：在有实验真值的变异集合中，比较"只按模型分数排序"和"按分数 + 可靠性排序"，看前 k 个变异中真阳性的比例。
- **意义**：直接对应研究者的实际工作（挑哪些变异去做实验）。

### R3. 案例研究（2–3 个，论文主图）
- **候选 1**：PKLR 启动子（MPRA 显示一致性低）。展示框架如何提示"此处模型不可信"，以及原因（如参考预测就不准、副本分歧大）。
- **候选 2**：BRCA1 剪接相关变异（SGE 真值）。展示模型与实验一致的情况，形成对照。
- **候选 3**：一个 GWAS 位点的非编码候选变异。展示在没有实验真值时，框架如何辅助判断。

### R4. LLM 解释的可靠性
- **指标**：比较三种解释——无约束 LLM（EVEE 式）、证据约束 LLM、证据约束 LLM 加自动核查——统计每条解释中有证据支持的陈述比例、与证据矛盾的陈述数，以及在模型不可靠的变异上是否承认不确定性。
- **评审**：自动核查加小样本专家盲评。

### R5（补充材料）小型专家评估
- **人数**：8–12 名变异解读或调控基因组学研究者。
- **任务**：判断一组有真值变异的预测是否可信。对照"只看分数"、"分数 + LLM 解释"、"AuraGenome-V"，用 Brier 分数衡量判断的校准程度。
- **定位**：辅助证据，不作为主结论。E3 的实验框架（任务库、计时、日志）可以直接复用。

## 7. 与竞品的区别（审稿人一定会问）

| | AlphaGenome Atlas | EVEE | RegTrust | **AuraGenome-V** |
|---|---|---|---|---|
| 规模 | 全基因组 | 420 万个 ClinVar 变异 | 单条序列 | 变异集合到碱基，多尺度 |
| 模型数 | 1 | 1 | 1（小型集成） | 多模型 + 多副本 |
| 可靠性信号 | 无 | 无 | 2 轴 + 适用域 | 多维画像，且在真值上标定 |
| 与实验证据对照 | 论文里有，界面里没有 | 外链 | 论文里有 | **框架核心，逐条可追溯** |
| LLM 解释 | 无 | 有，无约束 | 无 | **有，强制引用证据并自动核查** |
| 评估 | 基准性能 | LLM 当评委 | 误差相关性 | 识别错误预测、优先排序增益、解释可靠性 |
