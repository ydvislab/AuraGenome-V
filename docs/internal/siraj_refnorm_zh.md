# Siraj 标签改为"相对实测参照"后的重跑（规格写于运行之前，2026-10-30）

## 为什么

第二轮外部评审（GPT，2026-10-30）指出：Siraj 发表的效应值 `log2Skew` 是突变体 `log2FC` 减去**同一细胞、同一背景下全部 oligo** 中间 50% 的 `log2FC` 均值。这个基线用到了整个位点的测量。所以"只测 8 个变异"时，标签里已经隐含了其余几百个变异的信息。

预注册（preregistration_v2_siraj_zh.md）曾以"Spearman 对平移不变"为由忽略了这一点。但这个理由只对**打分**成立，对**拟合**不成立：
- 截距先验以 0 为中心；
- s² 由标签的平方均值估计；
- 锚点的斜率先验又依赖 s。

执行方在原始数据上核实了这一点：例如 K562、背景 `1:211556131:C:G:R:wC` 的中心均值为 6.9563，而实测参照 oligo 为 7.0477。756 个"细胞 × 背景"组每组都有且只有一个实测参照（m0）。

## 改动

- **标签**：`siraj_prepare.py --ref-norm` 写出 `pilot/data/siraj_ref/`。
  - 效应 = 突变体 `log2FC` − 同一背景、同一细胞的 m0 `log2FC`；
  - 标准误 = 两者标准误的平方和开方；
  - p 值由效应与标准误按正态近似重算。p 值只用于方向准确率（次要指标）的显著变异集合，不进入 P1–P4。
- **变化程度**：位点、行、变异都不变（149,950 行逐行对应）。每个实验内标签整体平移一个常数，平移范围 −0.79 到 +1.29，绝对值中位数 0.09。按新 p 值算的显著变异由 3,092 增加到 13,706，因为现在是相对参照判断显著性。
- **方法与参数**：完全不变（冻结 v2，`--common-eval --anchor-prior 0.95 --family-prior --controls`，200 次重复，seed 0），预测文件也不变。
- **报告脚本**：在次要结果里加 S3b（在 disc 选点上重新拟合匹配平均），与原 S3（随机选点）并列。这是评审要求的同条件对照。

**实验含义**：一次"8 个变异"的实验需要同时测未突变的参照构建体，论文要写明这一点。

## 运行（都在本规格提交并推送之后）

1. `SET=siraj_ref sh pilot/scripts/run_siraj.sh 8`：P1–P4 与次要结果，写到 `results/a1/siraj_ref/`。
2. `SET=siraj_ref sh pilot/scripts/run_siraj.sh 8 fold`：留出折检查点，写到 `results/a1/siraj_ref/c1/`。
3. `SET=siraj_ref sh pilot/scripts/run_comparators.sh siraj 8`：选点对照（停止阈值沿用已冻结的 r = 0.99），写到 `results/a1/siraj_ref/cmp/`。

- **界值、检验和判定规则与 Siraj 预注册第 6 节完全相同**（P1 下界 > −0.02；P2 受损比例上界 ≤ 0.15；P3 ≥ 0.03 且 p < 0.05；P4 > 0 且 p < 0.05；安全网 = P1、P2 成立且 P3 或 P4 成立）。

- 若安全网仍成立，论文主张不变，只更新数字；若不成立，按失败的那一项收窄主张（例如 P1 失败，就不能再说"有匹配轨道时不损害"），并在摘要中写明。
- 留出折检查和选点对照沿用各自规格（c1_robustness_zh.md、acquisition_comparators_zh.md）的判读规则。

## 不变的局限

Kircher 的效应来自原作者的模型估计，相对参照序列，不受这一问题影响；本次只重跑 Siraj。
