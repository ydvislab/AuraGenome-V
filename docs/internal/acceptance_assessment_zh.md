# TrackPilot 在 Bioinformatics 发表的可能性评估（2026-11-02）

这份评估是我的主观判断，不是统计预测。参照点：期刊整体接收率约 30%；"significance"不够的稿件会被直接退回，不送审。

## 1. 审稿人会怎么看现在的工作

**强项（审稿人会认可）**
- 两个独立数据集都做了预注册检验，而且结果都成立。这在这个领域很少见。
- 证据链完整：
  - 用没见过该位点的 checkpoint 复查过；
  - 与回归、主动模型选择（CODA / MODEL SELECTOR）、EIG 等做法都比过；
  - 失败的结果也报告了（v1 在有匹配轨道时会变差、提前停止规则不成立、Kircher 上方向准确率较差）。
- 问题真实存在：AlphaGenome 发表后，"我的细胞该用哪条轨道"是很多实验室都会遇到的问题。
- 方法简单、可解释，只有两个先验参数，而且事先固定、没有调过。

**弱项（按被拒风险从高到低）**
1. **效果幅度不大**：没有匹配轨道时，Spearman 提高 0.04–0.05；有匹配轨道时只是"不更差"。审稿人可能问："测 8 个变异只换来 0.05，值得吗？"
   - 应对：讲清楚这 0.05 相当于从"平均所有轨道"走到接近"事后最好的单条轨道"差距的一半以上。还要强调：随机测 8 个，反而比不测更差。
2. **只验证了一个模型**：AlphaGenome。"通用方法、工具"的说法缺证据。
3. **"没有匹配轨道"是模拟的**：K562 和 HepG2 都在 AlphaGenome 的训练数据里，只是我们把相关轨道藏了起来。Kircher 里的 SK-MEL-28 和胶质瘤系是真正没被覆盖的，但只有几个元件。
4. **方法层面的新意有限**：Box–Hill 判别设计、模型平均、共轭积分都是经典方法。熟悉统计的审稿人会说这是"已知部件的组合"。
   - 应对：Bioinformatics 接受这种定位，前提是工具好用、问题重要。
5. **使用门槛**：用户要先自己跑 AlphaGenome 的 ISM 打分（需要 API key），再做实验。如果工具不能一条命令跑完，会被认为"需要大量用户投入"。
6. **写法**：现在读起来像研究日志加审稿回复（见 `repositioning_plan_zh.md`）。

## 2. 分档估计

| 状态 | 估计接收概率 | 主要风险 |
|---|---|---|
| A. 现稿原样投 | 约 20–30% | 写法不像方法论文；没有工具；"significance"可能不够，直接退回 |
| B. 改写 + 做成 TrackPilot 工具（不加新数据） | 约 35–45% | 单一模型；"没有匹配轨道"是模拟的 |
| C. B + 第二个模型（Enformer 或 Borzoi），参数冻结 | 约 45–55% | 效果幅度 |
| D. C + 一个真正没被覆盖的细胞类型上的新数据集，或不同研究设计（跨位点的 GWAS 变异 MPRA） | 约 55–65% | 新数据上效果可能变小；那样只能如实写 |

"接收"指经过一到两轮修改后接收。大修本身是常态。

## 3. 推荐做法

做到 D 档，但要按优先级来，每一步都先写规格、冻结参数，再跑新数据（和之前的预注册做法一致）。

1. **第二个模型：Enformer**（首选）
   - 理由：它能在本机 M2 Pro 的 GPU（MPS）上运行；Borzoi 输入长达 524 kb，本机太慢。
   - 做法：在 Siraj 125 个位点和 Kircher 上重跑冻结的 TrackPilot，看 P1–P4 是否依然成立。
   - 意义：证明工具不绑定 AlphaGenome。
   - 需要：下载 Enformer 权重（约 1 GB，需你同意）；运行时间待实测，估计一个晚上到两天。
2. **新研究设计和新细胞类型**：跨位点的 GWAS 变异 allelic MPRA。
   - 场景：实验室在自己的细胞里测了一批 GWAS 变异，想预测剩下的。
   - 候选：
     - 精神疾病 MPRA（Cell 2024，hiPSC 来源神经元）；
     - 阿尔茨海默病小胶质细胞 MPRA（medRxiv 2025）；
     - MPRAVarDB 汇总的 18 个实验（30 多种细胞系）。
   - 需要：先确认数据是否公开、许可是否允许，再下载（需你同意）。AlphaGenome 打分需要用你自己终端里的 key。
3. **工具本身**：`pip install trackpilot`，两条命令完成：
   - `trackpilot suggest`：选要测的变异；
   - `trackpilot predict`：读入实测值，给出预测和报告。

   可选的 AlphaGenome 打分接口用用户自己的 key。

## 4. 不建议做的

- 把"计算机通用方法"作为主卖点，或者去证明在非基因组任务上有效。那会偏离期刊范围，而且需要另一套评估。
- 为了"泛化"去调参数。新数据上必须用冻结的方法，否则之前预注册检验的价值就没了。
