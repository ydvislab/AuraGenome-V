# 补充分析：方向准确率（事后、描述性；规格写于计算之前，2026-10-30）

## 为什么

第二轮评审指出，论文只报告 Spearman 相关（整体排序），却把结论说成"该信哪条轨道"。实验室更关心的往往是：**显著变异的方向（上调还是下调）判断对不对**。评审要求补充方向准确率。

## 定义（不新跑模型，只读已有运行记录）

- **显著变异**：沿用数据准备时的定义，p < 1e-5 且 |效应| ≥ 0.1。Kircher 来自 `build_variant_table.py`；Siraj 用相对实测参照重算的 p 值（`siraj_prepare.py --ref-norm`）。
- **方向准确率**：在留出的显著变异上，预测符号与实测符号一致的比例。
  - 带标签的方法用后验平均预测（`acc_bma`，含仿射校准的截距，所以符号可以与原轨道不同）；
  - 不用标签的参照（匹配平均、相关细胞平均、全轨道平均）直接用轨道预测的符号（`acc_pick`）。
  - 与 Spearman 一样，在同一组池外变异上打分（`--common-eval`）。
- **汇总**：每次重复先算，再在重复间取平均；某次重复的留出集里没有显著变异时，该次不计入。Kircher 先在区域内平均实验，Siraj 先在位点内平均两种细胞（只平均有显著变异的细胞）。没有任何显著变异的单位不计入，并报告单位数。
- **区间**：单位层面自助法 95% 区间（10,000 次，seed 0），报告为正的单位数。不做假设检验，不设界值，结果只作描述。

## 对比（与正文的 Spearman 对比一一对应）

Siraj（125 个位点，标签相对实测参照，`pilot/results/proxy_select_siraj_ref/`）：
- P1 对应：C1，k=8，v2 − 匹配平均；k=16 同；
- P3 对应：C3，k=8，v2 − 全轨道平均；

## 事先声明的读法

- 这是补充材料里的描述性结果，不改变任何预注册判定。
- 如果方向准确率与 Spearman 的结论方向一致，论文正文用一句话提及，数字放补充表。
- 如果某个对比方向相反（例如 Spearman 上非劣效、方向准确率却明显更差，区间整体在 0 以下），正文要如实写出，并相应收窄"该用哪条轨道"的说法。

## 补充诊断（看到结果之后加的，属于探索性分析）

按上面的规格算完后，Kircher 上 v2 的方向准确率明显低于匹配平均（C1，k=8：−0.133，区间 −0.264 到 −0.026），而 Spearman 几乎相同（例如 SORT1：0.643 对 0.648；方向准确率 0.74 对 0.88）。排序不变而符号变了，最可能的原因是仿射校准拟合出的截距：后验平均预测 = Σ w(a + b·z)，截距 a 让预测的零点不再对应"无效应"。

诊断：在 `proxy_select.py` 的 `evaluate()` 中加一列 `acc_bma0`，即去掉截距后的同一后验平均 Σ w·b·z 的符号准确率。这一列只多输出，不改变任何其他列，也不用随机数。按冻结 v2 配置重跑 Kircher 检验集（标签 `diag_dir/<element>`），并核对 `acc_bma` 与原运行逐行一致。这一诊断不是事先计划的，只用来解释原因，不替代上面的主要结果。

逐区域（C1，k=8，相对匹配平均）：带截距时除 LDLR（+0.095，匹配轨道本身差）外几乎都变差，SORT1 −0.127、MYCrs6983267 −0.178。去掉截距后，9 个区域平均 +0.008，基本与匹配平均持平；只有显著变异极少的两个区域仍差：FOXE1（5 个）−0.714，MYCrs11986220（11 个）−0.142。代价是 LDLR 在 8 个标签时的优势从 +0.095 降到 +0.016（16 个标签时回到 +0.09）。

诊断运行的 `rho_bma`、`acc_bma`、`rho_pick`、`acc_pick` 与原运行逐行一致（最大差 0）。

### 按事先声明的读法

Kircher 上出现了"Spearman 非劣效、方向准确率明显更差、区间整体在 0 以下"的情况，所以正文如实写出（§3.3 末段"Direction of effects (post hoc)"），局限中加一句。原因是截距：校准后的预测排序不变，但零点被截距移动。论文建议判断方向时用去掉截距的后验平均。这一建议来自看到结果后的诊断，正文已注明。Siraj 上带截距的方向准确率没有问题，可能因为效应已相对实测参照定义；这一点没有单独检验。
