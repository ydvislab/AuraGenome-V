# 适用性检查（预注册扩展，2026-11-04）

本文件和代码在运行任何适用性检查之前写好并提交。阈值在开发单位上选定并提交之后，才运行检验单位。

## 1. 要回答的问题

神经元 MPRA（`neuron_mpra_zh.md`）上，任何轨道都几乎预测不了实测效应（匹配轨道 ρ ≈ 0.07）。8 个测量值主要是噪声，TrackPilot 被噪声带离默认预测，比默认差 0.01–0.04。

**问题**：只用试点面板的 k 个测量值，能否判断"没有轨道承载这个实验的信号"，并在这种情况下退回默认预测？同时，在有信号的数据上不损失 TrackPilot 的增益。

## 2. 方法（只加一步判断，其余冻结）

对一个单位（位点、区域或实验）、一个情景、一次重复：

1. 照常用冻结的 TrackPilot 选 k 个变异，读入实测值 y_S。
2. **统计量**：混合模型的对数证据 E(y_S) = log Σ_h p(h) p(y_S | h)，即 `_posterior` 返回的 ll 的 logsumexp（含先验）。
3. **置换零分布**：把 y_S 在这 k 个变异之间随机打乱 B = 200 次（`numpy.random.default_rng([2, rep])`），每次重算 E。s² 对置换不变。
4. **P 值** = (1 + 置换中 E ≥ 观测 E 的次数) / (B + 1)。
5. **规则**：P > p* 时判为"无可追踪的信号"，输出默认预测（有匹配或相关轨道时为其均值，否则为全轨道均值，即 `prior_prediction()`）；否则输出 TrackPilot 的后验平均预测。

不变的部分：α、β、π、家族先验、可测池（`default_rng([0, rep])`，50%）、评估集（池外变异）、面板选择规则。

## 3. 数据与划分（AlphaGenome ALL_FOLDS）

| 数据 | 开发单位 | 检验单位 |
|---|---|---|
| Kircher | 5 个开发实验（PKLR-48h、F9、HNF4A、IRF6、BCL11A） | 11 个检验区域（17 个实验，同一区域内先平均） |
| Siraj | `cross_locus.py` 的 40 个开发位点（`default_rng(2611)`） | 其余 85 个位点（两种细胞先平均） |
| 神经元 | 159 个区域按字母序，`default_rng(2612).choice(159, 50)` 抽 50 个 | 其余 109 个区域（区域内片段先平均） |

- 情景：C1（全部轨道）和 C3（藏起匹配和相关轨道）；k = 8；重复 rep = 0–19。
- 神经元的总体结果已经看过（`kosicki_*/decision.txt`）。阈值只用开发单位来选，但检验单位的神经元区域不是完全未见过的数据。这一点在论文中写明。

## 4. 选 p*（开发单位）

- 网格：p* ∈ {0.05, 0.1, 0.2, 0.3, 0.5}。
- 目标：三组数据开发单位上"带检查的预测 − 默认预测"的平均值（C1 和 C3、三组数据等权平均），取最大。
- 差距小于 0.002 时取较大的 p*（检查介入得更少）。
- 选定后写进本文件第 7 节并提交，然后才运行检验单位。

## 5. 预注册假设（检验单位，k = 8）

- **A1（无信号的数据要退回默认）**：神经元 109 个检验区域，C1 和 C3 先在区域内平均。
  - 带检查减不带检查：平均 > 0，单侧 Wilcoxon P < 0.05；
  - 带检查减默认：单侧 95% bootstrap 下界 > −0.02。
- **A2（有信号的数据不损失增益）**：Siraj 85 个检验位点。
  - C3 带检查减全轨道均值 ≥ 0.03，单侧 Wilcoxon P < 0.05（对应 P3）；
  - C1 带检查减匹配均值：下界 > −0.02（对应 P1）；
  - 带检查减不带检查（C1、C3 平均）：下界 > −0.01。
- **判定**：A1 和 A2 都成立，判为"适用性检查能识别没有可追踪信号的实验，且不损失有信号时的增益"。否则如实报告哪一条没有成立。

**次要（描述性）**
- 各数据集、各情景被判为"无信号"的比例；
- Kircher 11 个检验区域上的同样比较；
- 神经元数据换成 Enformer 预测时的结果。

## 6. 局限（预先写明）

- k = 8 时置换检验的检验力有限，有信号但较弱的位点也可能被判为"无信号"。
- 神经元检验区域的总体结果已见过，所以 A1 是部分见过数据上的检验，证据强度低于前面的预注册检验。
- 只用了 20 次重复（冻结运行是 200 次），用于节省计算。不带检查的结果也用这 20 次重新计算。
